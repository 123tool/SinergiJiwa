## 💊 SinergiJiwa - Pusat Dukungan & Pencegahan Krisis Kesehatan Mental

SinergiJiwa adalah aplikasi web statis modern premium yang dirancang untuk menyediakan bantuan darurat, intervensi dini, serta skrining klinis mandiri bagi individu yang berada dalam krisis emosional atau kecenderungan bunuh diri. Proyek ini dibangun dengan komitmen penuh pada privasi pengguna (100% Client-Side Engine, tanpa pelacakan database eksternal).

## 🚀 Fitur Utama

1. **Direktori Krisis Darurat Terintegrasi**: Akses cepat sekali-klik menuju Call Center Kemenkes RI 119 Ext 8, Komunitas Rujukan Into The Light, serta Unit SAPA 129.
2. **Kuesioner Klinis PHQ-9 (Patient Health Questionnaire)**: Algoritma interaktif berbasis standar medis internasional untuk mendeteksi level depresi dari skala minimal hingga kritis.
3. **Simulator Taktis Box Breathing**: Alat bantu pernapasan interaktif berbasis state-machine JavaScript untuk menurunkan intensitas serangan panik (Panic Attack) dan kecemasan tinggi secara real-time.
4. **Modul Panduan Mitigasi**: Edukasi taktis langkah demi langkah bagi penyintas (diri sendiri) maupun penolong (orang terdekat).

## 🛠️ Spesifikasi Teknologi & Dependencies

Aplikasi ini menggunakan pendekatan arsitektur monolitik statis berkinerja tinggi tanpa kompilasi build yang rumit:
- **HTML5 Semantic Tags** (Optimasi Aksesibilitas & SEO)
- **Tailwind CSS v3.x** (Utility-First Responsive Styling Engine)
- **Lucide Icons** (Modern Vector Component Graphic Interface)
- **Vanilla JavaScript (ES6+)** (Manajemen State, Algoritma PHQ-9, & Simulator Box Breathing)
